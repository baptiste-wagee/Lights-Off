# 💡 Lights-Off

**Lights-Off** est un projet personnel que j'ai développé afin de mettre en pratique mes compétences en **Java** à travers la création d'un jeu de réflexion inspiré du célèbre puzzle *Lights Out*.

Le jeu a été entièrement réalisé en **Java**, avec pour objectif principal de progresser en programmation, en algorithmique et en conception d'applications.

## 🌐 Lien

[👉 *(Lights-Off)*](https://github.com/baptiste-wagee/Lights-Off)

## 📖 À propos du projet

Lights-Off est un jeu de réflexion dont l'objectif est d'éteindre l'ensemble des lumières présentes sur une grille.

La difficulté repose sur son fonctionnement : lorsqu'une case est sélectionnée, son état est inversé ainsi que celui de ses voisins directs (haut, bas, gauche et droite). Le joueur doit donc élaborer une stratégie afin de résoudre chaque grille.

Ce projet m'a permis de mettre en pratique les notions de programmation, d'algorithmique et de gestion de la logique d'un jeu.

L'objectif n'est pas seulement de développer un jeu fonctionnel, mais également de renforcer mes compétences en :

- Java
- Algorithmique
- Programmation Orientée Objet (POO)
- Gestion des événements
- Conception de jeux
- Organisation d'un projet logiciel

## 🚀 Technologies utilisées

- ☕ Java

## 🎯 Objectifs

- Développer un jeu de réflexion en Java.
- Améliorer mes compétences en algorithmique et en programmation orientée objet.
- Concevoir la logique d'un jeu reposant sur des interactions entre les différentes cases de la grille.
- Réaliser un projet concret afin d'approfondir mes connaissances en Java.
